# 玩家说明

## 启动

适用于 Windows 10／11。完整解压游戏包，双击 **TypeGameWASD.exe** 启动；`Settings.cmd` 用于打开设置。

仅 MOD 包需要自行提供兼容的原版游戏。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 切换／收起枪械 | 1、2 或鼠标滚轮 |
| 射击 | 回车，可按住连续射击 |
| 换弹 | R |
| 消耗 3 格能量补弹 | E |
| 切换打字／移动模式 | Tab |
| 小偷瞬移／警察按住举盾 | Shift |
| 返回 | Esc |

开局没有弹药。每打对一个完整单词获得 1 格能量，最多 6 格，用于补弹或使用角色技能；举盾时不能打字回能。

## 局域网

两台电脑连接同一局域网，启动游戏后在多人模式中创建或加入房间。MOD 会自动选择实际网络连接。
