# 玩家说明

## 启动

完整解压发布ZIP到有写权限的文件夹，双击根目录 **TypeGameWASD.exe**。完整包自动识别Classic目录并启动游戏；游戏退出后助手自动退出。双击 `Settings.cmd` 可查看设置或手动启动。不要在压缩软件内部直接运行EXE，也不要只复制其中一个文件。

ZIP内直接包含EXE与Classic目录。若在非常深的目录解压时提示0x80010135（路径太长），请改用较短的位置，例如 `C:\Games\TypeGame`，重新完整解压。

仅MOD包需要选择兼容的经典版TypeGame.exe。当前支持TypeGame 8.00.0035，启动时会校验游戏与资源版本。

Windows 10／11上的.NET Framework 4.x运行环境适用；程序与原游戏均为x86，可在64位Windows运行。图形兼容层、DirectX7 VB DLL与C++运行库由完整包提供，采用本地清单加载，不执行DLL注册或请求管理员权限。部分Windows环境的局域网功能可能需要系统的旧版DirectPlay组件；程序不会自行安装Windows功能。

## 操作

| 操作 | 按键 |
| --- | --- |
| 八方向移动 | WASD |
| 切换／收起枪械 | 1、2或鼠标滚轮 |
| 射击 | 回车，按住连续射击 |
| 从备弹换弹 | R |
| 消耗三点能量立即补弹 | E |
| 原版文章打字／移动 | Tab |
| 小偷瞬移／警察按住举盾 | Shift |
| 子弹速度 | [、]，联网仅房主可调 |
| 胜负界面 | Esc返回，松开后再按回车重开；联网需双方准备 |

开局两把枪均零弹药。每个正确完整单词增加一点能量，最多六点；满格后文章仍可继续。瞬移消耗一点，至少间隔0.35秒；举盾每秒消耗一点，松开保留剩余时间，举盾不能打字、射击或补弹。

E优先补齐弹匣，剩余进入备弹：AK每次30发、备弹上限90；霰弹每次8发、备弹上限24。R保留余弹，分别需要1.8／2.4秒；E可以立即取消当前换弹并补给。两种技能共用库存。

双方各三颗血，中弹后0.5秒无敌。霰弹每发6颗，地面散布20度、射程260像素；默认弹速450像素／秒。建筑、车辆及树冠挡人挡弹，水面与中央细长灌木花坛只挡人物；瞬移也不能穿过障碍。

## 局域网

两台电脑分别启动MOD，从原版多人菜单创建／加入。房主决定弹药、伤害、胜负与弹速。1.0使用v15协议，与使用同一协议的旧开发版兼容。首次在新电脑或新解压位置使用联网时，Windows可能要求对游戏设置网络权限；本程序不修改防火墙、路由、UAC或安全通知。

每次启动MOD自动选择已连接的实际以太网／Wi-Fi IPv4 网卡，优先默认连接，再根据当前地址及子网掩码定向搜索。VirtualBox、VMware、隧道及VPN网卡不参与选择，无需调整Windows广播路由。日志中的`LAN discovery adapter=... local=... broadcast=...`可核对选择结果；网络切换后重新启动游戏即可重新选择。两台电脑仍需位于可互通的局域网，访客Wi-Fi隔离或系统防火墙限制需按实际网络处理。

## 音乐与问题排查

Paris文件为 `audio/MOON-Paris.m4a`。若包内没有该文件，可自行提供；缺少外部配乐时继续使用原版音乐。配乐首次装备枪后触发，对局内持续，菜单、结算或失焦暂停。枪声与原游戏声音随完整包保留。

启动失败时确认完整解压、Classic目录及compat目录齐全，查看 `logs/TypeGameWASD.log`。问题反馈请附版本、Windows版本、复现步骤及相关日志；发送前删除个人路径。

原创MOD、原版游戏和第三方素材的许可分别见根目录LICENSE.txt、Classic/License.txt及compat/audio中的许可记录。
