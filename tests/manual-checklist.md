# 手动验证清单

- 完整解压到另一目录，双击TypeGameWASD.exe进入游戏；Settings.cmd仅打开设置，退出游戏后助手退出。
- 后台循环故障时启动器显示原因并恢复可启动状态；停用会话后没有工作线程继续访问游戏。
- 缺失或错误的Classic文件明确报错，不静默选择另一份安装。显式--game及--attach仍可使用。
- 两种角色、三种武器状态、持盾的八方向跑步／待机和开火效果正常，脚底及比例保持现有版本。
- Tab打字、一词一格、满格继续打字、Shift瞬移／持盾、E即时补弹、R换弹与键盘释放门控正常。
- 双方三颗血、半秒无敌、胜负画面、Esc返回与双方准备重开正常。
- 建筑／车／树冠挡人挡弹，水面和中央细长花坛挡人；道路正常，瞬移不能穿越。
- 音乐对局持续、菜单／结算／失焦暂停，枪声正常；缺少外部配乐时原版音乐保留。
- 在已授权的相同局域网中双机验证角色、技能、弹药、伤害和胜负。提前核对程序及网络规则，不通过安全设置变更消除提示。
- 多网卡环境中保持系统路由原样，确认日志选实际有线／Wi-Fi子网，刷新能发现对端并加入；停用MOD后原版地址挂钩恢复。换电脑或网络后重新启动，确认地址从当前环境计算。
- 同一显示环境只运行一个游戏实例，避免旧版DirectDraw在第二份初始化时失败；开始实机前核对用户实例，保留用户游戏。
- 只关闭本次创建并核对路径的测试进程；不关闭用户实例。记录哪些环境实测，哪些仅离线模拟。
