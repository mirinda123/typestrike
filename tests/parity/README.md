# 1.18.2 重构对照

`BehaviorProbe.cs` 是同一套固定种子输入，分别引用已交付的 1.18.1 和当前程序集编译为两个 x86 测试进程。各阶段输出长度及 SHA-256；对应结果必须相同。此目录独立于常规测试工程，不在生产代码中添加测试入口。

覆盖弹药／换弹／供弹、技能／举盾／瞬移、单人弹道、双方房主与丢包／重复动作、十组八向精灵上传、动画控制字段与开火特效快照、全部嵌入资源、两个地址下的完整原生重定位代码。

`BaselineAnimation.cs` 固定保留重构前 1.18.1 的动画条件和更新顺序，仅用反射读取私有字段，代替原来的无限 `Poll`。基准来自修改前源码备份，不能随生产代码一起“修正”。测试只分配自己的进程内存，不打开游戏、联网监听或注入用户进程。

唯一有意排除的旧值是客户端 `PelletsFired` 统计：旧版错误地将霰弹按七颗累计；1.18.2 按实际六颗累计。此值不写入网络包；常规 `ShotgunBalanceTests` 单独断言双方统计一致。

从项目根目录执行：

```powershell
.\build.ps1 -Test
python tools\verify_refactor.py --baseline 'C:\path\to\TypeGameWASD-1.18.1\TypeGameWASD.exe'
```

默认报告写到 `artifacts/refactor-parity/`。不要把基准程序复制进源码或发行包。
